# Photography

Every image on the site is registered in `src/data/images.ts`.

The files in `placeholders/` are flat brand-toned stand-ins. To replace one:

1. Add the photograph to this folder (for example `images/newmills-aerial.jpg`).
2. In `src/data/images.ts` update `src`, `width`, `height` and write a real `alt`.
3. Set `placeholder: false`. The small caption describing the intended shot disappears.

Photography direction, for reference: Cornish architecture, stone, slate, fields,
material textures, large windows, courtyards, rain, warm interiors, winter as well
as summer. Cornwall should look good in January.
